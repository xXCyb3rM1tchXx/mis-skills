# Stage 8-B — Gemini External Deep Research Fallback

Conditional workaround only when native Deep Research is unavailable/exhausted at Stage 8, or user explicitly chooses Gemini.

Architecture:
- Host (ChatGPT Work or Claude Cowork) = SOP Controller / Reconciliation Gate
- Gemini = Research Engine
- User = transfer bridge unless a trusted connector exists

Flow:
same account branch → generate Gemini Handoff → user runs Gemini Deep Research → user returns Markdown dossier → same host branch reconciles → ACCOUNT_INTELLIGENCE_COMPLETE.

## Handoff must include
Campaign Context
Active Account
Previously Validated Account Data
Validated Contacts
Contact Strategy 4C
Enrichment outcomes relevant to research
Known Gaps
Contradictions / Red Flags
Research Boundary
Evidence Policy
Provenance / Sources

Minimize PII. Names/roles may be needed; email/phone normally are not.

Preferred files:
GEMINI_RESEARCH_HANDOFF_[ACTIVE_ACCOUNT].md
EXTERNAL_STAGE_8_DOSSIER_[ACTIVE_ACCOUNT].md

## Gemini prohibitions
No outreach, first-contact choice, CTA, sequence, GHL, contact enrichment, new emails/phones, Apollo, FullEnrich, proposal, pilot, future timeline, ROI or unsupported business case.

## Host reconciliation
No new research. Do not trust Gemini self-PASS.
Preserve facts, sources and account-specific detail.
Downgrade unsupported authority/headcount/benefit/need/fit claims.
Remove Stage 9–11 invasion.
Preserve Discovery Gap Map, Red Flags and Preservation Ledger.

If required dossier sections/provenance/ledger are structurally missing:
BLOCKED_BY_INCOMPLETE_EXTERNAL_RESEARCH
Falta: [exact items]

Only host may declare:
SOURCE_SET_VALIDATION: PASS
RECONCILIATION_GATE: PASS
INTELLIGENCE_PRESERVATION_LEDGER: COMPLETO
ACCOUNT_INTELLIGENCE_COMPLETE
READY_FOR_STAGE_9
